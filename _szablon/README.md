# Tytuł warsztatów

Wydarzenie: nazwa wydarzenia, miejsce
Data: DD.MM.RRRR
Prowadzący: imię i nazwisko (EnviroSolutions)

Krótki opis: czego uczestnik się nauczy, w 2–3 zdaniach.

## Co przygotować

- wersja QGIS (np. QGIS 3.44 LTR),
- wtyczki, jeśli są potrzebne,
- inne oprogramowanie lub konta.

## Pobranie materiałów

Gotowa paczka ZIP jest w zakładce [Releases](https://github.com/envirosolutionspl/warsztaty-gis/releases) pod tagiem z nazwą tego katalogu.
Pliki większe niż 50 MB są dołączone wyłącznie do Release (wymień je poniżej).

| Plik | Rozmiar | Gdzie |
|------|---------|-------|
| przyklad.gpkg | 120 MB | Release |
