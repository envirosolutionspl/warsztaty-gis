## Jak pobrać materiały

**Uczestnicy:** wejdź w link w kolumnie „Paczka ZIP” i pobierz plik `.zip` z sekcji *Assets*.
Paczka zawiera tylko materiały z danych warsztatów. Duże pliki danych są dołączone osobno w tym samym miejscu.

Rozpakuj paczkę na dysk lokalny (nie pracuj na pendrivie ani bezpośrednio w ZIP) i postępuj według README w katalogu warsztatów.
